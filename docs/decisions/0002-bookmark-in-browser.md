# 0002 ブックマークはMVPではブラウザに保存する

- ステータス：提案中
- 日付：2026-10-28
- 関連：FR-13、FR-14、FR-15、[data-model.md](../data-model.md)

## 背景

買い手が複数の出品を見比べるためのブックマークを、どこに保存するかを決める必要がある。

## 選択肢

- A：ブラウザ（localStorage）に保存する。ログイン不要
- B：アカウントを作り、GoのDBに保存する

## 決定（案）

MVPはAを採る。端末をまたぐ同期が必要になったらBに移る。

## 理由

買い手は出品を見比べる途中で保存するので、そこでログインを挟むと離脱する。端末をまたぐ同期は後から足せる。

## 影響

- MVPのWebにはログインがなく、認証まわりの実装がいらない
- ブラウザのデータを消すとブックマークも消える。画面でその旨を伝える
- Bに移るときのために、保存形式にバージョン番号を付ける
- Bを採る場合は `auth.md` を新設し、ログイン画面と `/api/me/bookmarks` が増える
