# 0003 証明書は発行時点のスナップショットにする

- ステータス：提案中
- 日付：2026-10-28
- 関連：FR-07、[data-model.md](../data-model.md)

## 背景

証明書のページを、発行した時点で固定するか、端末の最新の記録に追従させるかを決める必要がある。

## 選択肢

- A：発行時点のスナップショット。発行ごとに別の証明書番号を振る
- B：端末ごとに常に最新の記録を表示するページ

## 決定（案）

Aを採る。

## 理由

出品後に内容が変わると、買い手が見た情報と食い違い、トラブルの元になる。出品し直すときは再発行すればよい。

## 影響

- 発行後に記録や評価は変わらない。例外は出品先だけ（[0006](0006-listing-link.md)）
- 再発行したら古い証明書を「再発行済み」にし、新しい番号へのリンクを持たせる
- 失効・再発行の条件と、誰が操作するかをアプリ・Goと決める必要がある
