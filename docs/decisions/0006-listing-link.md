# 0006 出品先を証明書に登録して表示する

- ステータス：提案中
- 日付：2026-10-28
- 関連：FR-05、[security.md](../security.md)

## 背景

証明書はQRや番号で誰でも開けるので、他人の証明書を自分の出品に流用される恐れがある。買い手が「この証明書は今見ている出品の端末のものか」を確かめる手段が要る。

## 選択肢

- なにもしない（機種名だけで判断してもらう）
- 出品者が出品URLを証明書に登録し、証明書に表示する
- 製造番号の一部を表示する

## 決定（案）

出品URLの登録と、製造番号の末尾表示を組み合わせる。どちらもアプリから登録する。

## 理由

- 流用されても、証明書に別の出品が表示されていれば買い手が気づける
- 製造番号は受け取り後の照合に使える。Yahoo!フリマは携帯電話の出品で製造番号の記載を求めているので、出品側の情報とも突き合わせられる
- 製造番号はAndroid 10以降、一般のアプリから取得できないため出品者の入力になる。画面では「出品者申告」と明記する
- 登録・変更を本人確認済みのアプリに限れば、第三者による書き換えを防げる

## 影響

- 出品先は発行後に追加・変更できる唯一の項目になる（[0003](0003-certificate-snapshot.md) の例外）
- 出品先はハッシュの対象外でチェーンに載らない。保証は運営者のDBとアプリの本人確認に頼る
- 登録用のAPIはアプリとGoの間で決める。Webは表示するだけ
- 製造番号は末尾しか表示しない（NFR-05）
