# 0007 出品用カード画像はWebで生成する

- ステータス：提案中
- 日付：2026-10-28
- 関連：FR-11、FR-17、[features/qr.md](../features/qr.md)

## 背景

出品画像に使うカード画像（QR・証明書番号・機種・評価）を、Webとアプリのどちらで作るかを決める必要がある。

## 選択肢

- Web：Next.jsの画像生成で `/c/[番号]/card.png` を返す
- アプリ：Kotlinで画像を描画して端末に保存する

## 決定（案）

Webで生成する。アプリの「出品に使う」ボタンは出品用素材ページ（`/c/[番号]/share`）を開く。

## 理由

- QR・番号・機種・評価のレイアウトを1か所で管理できる
- OGP画像と同じ仕組みを共用できる（FR-17）
- 将来iPhoneや他の機器に広げても、画像の作り方を変えずに済む

## 影響

- Webに出品用素材ページが増える
- スマホのブラウザから写真に保存する手順を用意する必要がある（Web Share APIなど）
- アプリ側は画像生成を実装しなくてよい
