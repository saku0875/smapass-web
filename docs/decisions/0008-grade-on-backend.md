# 0008 評価はバックエンドで算出する

- ステータス：提案中
- 日付：2026-10-28
- 関連：FR-02、[data-model.md](../data-model.md)

## 背景

端末の状態の評価（総合評価と項目別評価）を、どこで計算するかを決める必要がある。

## 選択肢

- バックエンド（Go）で算出してAPIで返す
- Webフロントで記録データから算出する

## 決定（案）

バックエンドで算出する。Webは結果と説明文を表示するだけにする。

## 理由

アプリ・Web・将来のフリマ連携で同じ評価を出すため。評価ロジックを1か所に置けば、変更しても食い違わない。

## 影響

- APIが総合評価・項目別評価・説明文をまとめて返す必要がある
- 評価の根拠を文章で返してもらい、Webはそのまま表示する（FR-02）
- 評価ロジックはスナップショットに含める。ロジックを変えても発行済みの証明書の評価は変わらない（[0003](0003-certificate-snapshot.md)）
