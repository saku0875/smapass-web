# 0014 証明書は発行時点で固定せず、端末の最新の状態と全期間の履歴を表示する

- ステータス：提案中
- 日付：2026-11-07
- 関連：FR-01、FR-07、FR-11、FR-17、FR-19、[data-model.md](../data-model.md)、[screens.md](../screens.md)
- 置き換え：[0003](0003-certificate-snapshot.md)の全体

## 背景

[0003](0003-certificate-snapshot.md)では、証明書を発行時点のスナップショットにし、内容を変えたいときは再発行する案を採った。

smapass-back（develop 6a8a590）は、証明書の発行・再発行・スナップショット・証明書単位の失効を持たない。`/api/devices/{id}` は端末の最新の観測値と、全登録期間の状態計測の履歴を返し、新しい計測が届くたびに中身が変わる。

## 選択肢

- A：Back に証明書のスナップショットを追加してもらう（[0003](0003-certificate-snapshot.md)のまま）
- B：Back の方式に合わせ、端末の最新の状態と全期間の履歴を表示する

## 決定（案）

Bを採る。

## 理由

- Back がすでにこの方式で実装されており、Web だけで発行日や失効の状態を作れない
- 持ち主が替わっても全期間の履歴が残るので、中古で何度売られても使い続けられる

## 影響

- 買い手が見た内容が、後から更新されることがある。そのため次のようにする
  - 「最終計測：日時」を概要画面と詳細画面の目立つ位置に出し、リアルタイムの端末の状態ではないことを明記する
  - カード画像・OGP には発行日の代わりに機種と最終計測日を載せる（FR-11、FR-17）
  - `spec.collected_at` と `status.collected_at` は別の時刻のことがあるので、端末情報とバッテリーにはそれぞれの計測日を添える
- FR-07（失効・再発行の表示）は対象がなくなるので削除する。IDは欠番にして再利用しない
- 非公開に切り替えられた端末は 404 になり、「見つからないか、非公開に設定されています」と表示する
- 計測値は null になり得る。null は「不明」と表示し、0 や「異常なし」に置き換えない
- 出品時点の内容を残したい場合は、カード画像やスクリーンショットに頼ることになる。必要になったら新しいADRで改めて検討する
