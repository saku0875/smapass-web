# 0015 IMEIの末尾表示をやめ、買い手が入力したIMEIで照合する

- ステータス：提案中
- 日付：2026-11-07
- 関連：FR-05、FR-19、NFR-05、[security.md](../security.md)、[screens.md](../screens.md)
- 置き換え：[0011](0011-device-data-items.md)のうち「出品との照合欄にIMEIの末尾4桁を表示する」「Webに渡すのはIMEIの末尾4桁だけにする」の部分

## 背景

[0011](0011-device-data-items.md)では、出品との照合のために IMEI の末尾4桁を表示し、届いた端末で `*#06#` を押して比べてもらうことにした。

smapass-back（develop 6a8a590）の表示用 API は、IMEI の全桁も末尾4桁も返さない。IMEI は `/api/devices/search?imeis=` で UUID を引くためにだけ使う。出品先（listing）も Back には未実装。

## 選択肢

- A：Back に末尾4桁を返すよう依頼し、表示を続ける
- B：買い手が届いた端末の IMEI を入力し、Web が検索 API で UUID を引いて、開いているページの UUID と同じかを表示する

## 決定（案）

Bを採る。

- 結果は「この証明書の端末です」「別の端末の証明書です」「この証明書の端末とは確認できませんでした（見つからない）」「照合できず（通信エラー）」を分けて出す
- IMEI はフォームの値からブラウザで直接 Back の API を呼ぶ。Web のページ URL（`?imei=` など）に入れず、Web のサーバー（Vercel のログなど）を経由させない。入力欄には `name` を付けず、JavaScript なしで送信されても URL に載らないようにする
- 照合後は入力欄を空にし、画面に IMEI を残さない
- 入力は15桁とチェックディジットを Web でも確かめる

## 理由

- 末尾4桁より確実に照合できる（4桁では1万通りしかない）
- Back に表示用の追加を求めずに済み、表示用 API に IMEI の一部も流さない方針を保てる

## 影響

- FR-05 を「出品先の表示」から「届いた端末との照合」に変える。出品先の表示は Back が実装したら足す
- 非公開の端末は検索結果に出ないので、「見つからない」としか表示できない。ただしページが開けている端末は公開中なので、見つからなければ別の端末か打ち間違いと考えてよい
- 受け取る前（出品を見ている段階）には照合できない。出品と証明書のひも付けは、出品先の表示（Back 未実装）を待つ
- IMEI は Back のアクセスログに残らない前提（smapass-back の docs/api.md）。前提が変わったら見直す
